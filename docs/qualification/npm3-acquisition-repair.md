# SHA512-bound archive acquisition repair

The third repository-disjoint product cohort remains **17/30 complete**. Its frozen acquisition found 97 missing locator occurrences. Eight use unsupported Git sources. Of the other 89, 80 refer to `registry.npmmirror.com` URLs with SHA512 integrity, which the npmjs-only downloader refused; nine refer to npmjs URLs with SHA512 integrity but shared a digest first encountered at the mirror. The collector then reused the first unavailable result for that digest. This follow-up repairs the acquisition harness; it does not change the product's archive verifier or retroactively change the frozen score.

The collector now retries a digest when it sees a new permitted retrieval URL. For the measured `registry.npmmirror.com` host only, it tries the identical path at `registry.npmjs.org` and accepts the bytes only when their SHA512 matches the original lockfile SRI. It records both the locked source URL and the retrieval URL. The downloader's existing npmjs-only HTTPS rule and byte budget remain in force. A mismatch or unavailable alternate stays unavailable. Authored tests cover a mirror fetch, a later permitted URL for the same digest, and a byte mismatch.

In a **posthoc development replay** of [Faicad/faijs-freecad PR #7](https://github.com/Faicad/faijs-freecad/pull/7), 293 archive identities reused the original read-only cache and 63 fetched from npmjs through the mirror-path rule. All 356 identities became available; both collector sides validated. Independent labels became complete, and the unchanged `c140aed` product binary returned a complete advisory review matching all 250 assessable events with no fact mismatch. No package lifecycle script ran. The [compact receipt](evidence/npm3-acquisition-repair-20261110.json) binds the local files and helper hash. This case was selected and inspected before the repair, so it provides no unseen qualification credit.
